# Legacy assets (archived 2026-05)

이 폴더의 파일들은 **활성 사이트에서 더 이상 사용되지 않는 과거 브랜딩 자산**입니다.
신규 브랜드는 `/app_icon.svg` (navy gradient + 흰색 꽃)로 통일되었습니다.

## 보존 이유

- **외부 캐시 호환성**: 카카오톡 OG 캐시, Google 검색 인덱스, 트위터 카드 캐시
  등은 일정 기간 옛 URL을 참조할 수 있음. 90일 정도 유지 후 안전하게 삭제.
- **Git 히스토리**: 직접 삭제하면 히스토리에서 찾기 번거로워짐. 폴더로
  옮기면 커밋 1번에 의도가 분명히 남음.
- **롤백 안전망**: 새 디자인에 문제 발생 시 즉시 되돌릴 수 있는 백업.

## Next.js 빌드 처리

`public/_legacy/` 의 파일은 **여전히 정적 파일로 서빙**됩니다 (Next.js는
서브폴더 구분 없이 `public/` 하위 모두 노출). 따라서 `/<filename>` URL이
404 가 되었지만 `/<sub>/<filename>` 형태로는 접근 가능합니다.

활성 사이트의 모든 신규 페이지는 `/app_icon.svg` 또는 `/icon-{size}.png` 만
참조해야 합니다.
