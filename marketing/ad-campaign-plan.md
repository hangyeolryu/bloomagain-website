# 결 테스트 유입 광고 — 소재 3종 + Meta 세팅 + 카피

목적지: 앱스토어가 아니라 **tita-app.com/gyeol (무가입 테스트)**.
테스트가 대신 팔고, 공유가 공짜 증폭을 만든다. 다운로드는 리타게팅으로.

전략 근거: docs(korea) 없음 — 대시보드 데이터(완료 84, 공유율 13%,
유형 83%가 조용·깊은 결) 기반. 반응층 = 내향·사색·진심형.

## 타겟 (Meta: 인스타+페북)
- 성별: 여성 (남성도 열어두고 성과 보고 조정 가능)
- 나이: 만 45 ~ 65+ (65+ 버킷이 60대 포함)
- 지역: 대한민국
- 관심사(선택): 여행·등산·원예·반려동물·독서·건강/웰빙·트로트·요가·캠핑
  또는 Advantage+ 광범위로 두고 픽셀 최적화(고령층은 광범위가 종종 유리)
- 60대 도달 강화: 페북 피드 비중 ↑ + **유튜브(구글광고)** + **카카오모먼트** 병행
- 유사타겟: 테스트 완료 100명 넘으면 lookalike 생성

## 캠페인 구조 (돈 태우기 전 학습)
1. 소액 테스트(10~20만원): 소재×훅 3종 A/B → **테스트 완료 1건당 비용**
2. 리타게팅: 테스트 완료·미다운 → 다운로드 광고(따뜻한 청중, 저렴)
3. 승자 확대: 이긴 조합만 증액 → **본인인증 완료(활성화)당 비용** 주시

## Pain Point 지도 (카피 근거)
1. 창피함·자존심(최대): "앱으로 친구라니, 내가 그렇게 외로워 보이나"
   → 외로움이 아니라 취향·까다로움으로 리프레임
2. 이상한 사람 걱정: 보험·돈 얘기·물건 팔이·포교 (='사기'의 실체)
   → 단어 대신 구체 상황을 귀엽게 + 티타지기
3. 데이팅앱 오해: "남편/애들이 보면" → 찻자리·수다 프레임, '만남' 어감 제거
4. 티키타카 노동: 안 맞는 사람과 대화 이어가기 = 일
   → 결이 맞으면 첫 대화부터 편함
5. 기대 실망: "어차피 아무도 없겠지" → 유형 분포·후기 소재(추후)
서브카피 상비용: "연애 앱 아니에요. 차 마시고 수다 떠는 앱이에요."
